Війти в систему

Адмінка сайту «Гроно любові». Введіть GitHub Token з правами Contents: Read and write.

Токен створюється в GitHub → Settings → Developer settings → Personal access tokens. Не діліться ним з іншими.

Адмінка — Гроно любові

Крок 1: Завантажити контент

Натисніть «Завантажити з GitHub». Контент підхопиться з репозиторію.

Крок 2: Редагувати

Оберіть розділ і змініть поля справа. Можна редагувати всі дрібниці: тексти, посилання, зображення.

Крок 3: Зберегти

Натисніть «Зберегти в GitHub». Контент збережеться в репо. Головна сторінка зараз показує повний додаток і не підвантажує цей файл — перевірте зміни через «Перегляд збереженого контенту» нижче.

Перегляд збереженого контенту

Щоб переконатися, що фото та тексти збереглися правильно, відкрийте сторінку перегляду: вона підвантажує content/site-content.json і показує Hero (зображення та заголовок).

Відкрити перегляд збереженого контенту

Корисне

Фото: завантажуйте в блок «Медіа» — одразу кілька файлів (drag-and-drop або вибір). Потім кнопкою «Вставити в Hero» / «Вставити в Про нас» підставити URL.

У полях зображень можна вставляти будь-який URL або шлях, наприклад /images/файл.jpg.

Контент

Медіа: завантаження фото

Як додати нове фото:
1) Завантажте файл (перетягніть сюди або натисніть зону) — воно збережеться в репозиторій.
2) Натисніть «Використати для Hero» або «Використати для Про нас» — фото одразу підставиться в обраний розділ.
3) Натисніть «Зберегти в GitHub» у бічній панелі. Перевірте результат через сторінку «Перегляд збереженого контенту» (головна сторінка поки не використовує цей контент).

Перетягніть фото сюди або натисніть, щоб обрати файли

JPG, PNG, WebP, GIF. Можна кілька файлів одразу.

Останні завантаження — натисніть, куди вставити

Сирі дані (JSON)

Для складних правок. Змініть JSON, натисніть «Застосувати», потім «Зберегти в GitHub» у бічній панелі.
