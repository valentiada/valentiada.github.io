Адмінка — Гроно любові

Крок 1: Завантажити контент

Вставте GitHub Token і натисніть «Завантажити з GitHub». Токен потрібен з правами Contents: Read and write.

Крок 2: Редагувати

Оберіть розділ у випадаючому списку і змініть поля справа.

Крок 3: Зберегти

Натисніть «Зберегти в GitHub». Сайт оновиться після деплою на GitHub Pages.

Що важливо

GitHub Token обовʼязковий: створіть у GitHub → Settings → Developer settings → Personal access tokens з доступом Contents: Read and write.

Далі: «Завантажити з GitHub» → редагуйте справа (Сайт, Hero, Про нас, Футер) → «Зберегти в GitHub».

Фото: можна вказати URL у полях зображень або завантажити файл нижче — він збережеться в images/uploads.

Візуальний редактор

Оберіть розділ і змініть поля. Зміни збережуться лише після натискання «Зберегти в GitHub».

Завантаження фото в GitHub

Перетягніть зображення сюди або оберіть файл. Після завантаження URL можна вставити в поле зображення поточного розділу.
